# 06 地图与基站摆放

## 一、要解决的问题

地图模式要在巷道图上显示"某某在哪"。定位数据只告诉我们每个人**离他最近的基站**，基站有**名字**，但**没有可用坐标**。所以要做两件事：

1. 把矿上的 CAD 图变成网页能显示的底图；
2. 让用户在底图上手动点出每个基站的位置（摆放）。摆好后，"某某在某基站"就能画成图上的一个点。

## 二、坐标系

地图统一用 **EPSG:4527**（CGCS2000 / 3 度带高斯投影，第 39 带，中央经线 117°E）。图上和数据库里的坐标都是 CAD 图上的原始数字：东向 `39482000`（8 位，带 `39` 带号前缀），北向 `3852000`（7 位），单位米。

CAD 图的基准是 2000 还是西安 80，从图上看不出（见 `00` 第 16 项），但对本功能没有影响：基站是用户在这张底图上点出来的，两者用同一套数字；我们不把这些坐标和卫星地图、GPS 等外部数据叠加。日后要叠加外部数据时再处理基准。

前端用 proj4 注册：

```text
EPSG:4527 = +proj=tmerc +lat_0=0 +lon_0=117 +k=1 +x_0=39500000 +y_0=0 +ellps=GRS80 +units=m +no_defs
```

**轴顺序的坑**：EPSG:4527 官方轴顺序是"先北后东"，而 CAD 图和我们的数据是"先东后北"。WMS 1.3.0 会按官方顺序理解坐标，底图会整个错位或空白。**前端请求 GeoServer 一律用 WMS 1.1.1**（永远先东后北），并在代码注释里写明原因。

## 三、底图制作

CAD 图很大（14.5 MB，转换后 11 万多条线、5.8 万条文字、113 个图层），直接在浏览器画会很卡，所以在服务器上渲染成图片，浏览器只拼图片，这就是 GeoServer 的作用。

```text
矿上的 CAD 图 (.dwg)
   │ ① dwg2dxf（libredwg）转成 DXF
   │ ② 挑选图层，转成 GeoPackage（ogr2ogr / GDAL）
   │ ③ 发布到 GeoServer，配样式
   ▼
GeoServer ──WMS 1.1.1──▶ 前端 OpenLayers
```

- **GeoServer**：读地图数据，按请求的范围和缩放画出图片返回的软件；**GeoPackage** 是单文件的地图数据格式；**DXF** 是 CAD 的开放交换格式（DWG 是二进制，工具读不了）。
- **① 转 DXF**：DXF 里的中文是 GBK 编码。
- **② 挑选图层**：113 个图层里很多是地质、钻孔、等值线，与"人在哪条巷道"无关。先出一份图层清单（名称、实体数量、类型、预览图），**由你挑选**。可能相关的有煤巷、岩巷、巷道注记、工作面注记、避灾路线、通风符号，以预览为准。转成两个图层：**线**（巷道轮廓）和**文字**（巷道、工作面名称）。
- **③ 发布**：GeoServer 用官方 Docker 镜像（版本建设时选定），线和文字各配一个样式（深色底、青绿色线条）。
- **地图范围**不用 DXF 文件头里的 `EXTMIN`/`EXTMAX`（它把图纸外的杂物也算进去，范围偏大），而是选好图层后按实际数据计算，存进地图配置。

已知的坑：

| 坑 | 应对 |
| --- | --- |
| GeoServer 的 Docker 镜像没有中文字体，文字显示成方块 | 镜像里装中文字体，样式里指定字体名 |
| DXF 中文是 GBK | 转换时显式指定编码，转完抽查几条中文 |
| 单个图层实体十几万 | GeoPackage 建空间索引；样式按比例尺控制，缩小时不画文字 |

## 四、前端地图

OpenLayers + proj4。图层从下往上：

| 层 | 内容 | 来源 |
| --- | --- | --- |
| 1 | 巷道线 | GeoServer WMS 1.1.1 |
| 2 | 巷道文字 | GeoServer WMS 1.1.1 |
| 3 | 基站图标 | 我们的接口，前端矢量图层 |
| 4 | 人员图标 | 同上 |

基站和人员只有几百个点、每 30 秒变一次，直接在前端画，可点击、可拖动，不放进 GeoServer。

| 对象 | 样式 |
| --- | --- |
| 基站 | 小图标，通讯正常（青绿）/ 中断（灰）/ 故障（红）；缩放较小时可隐藏 |
| 人员 | 头盔小人，有仍在发生的告警（口径见 `05`"已上线告警"）的用醒目颜色；同一基站多人合并成一个图标显示人数 |

**定位到某人**：先找到他所在的基站。基站已摆放：地图平滑移动并放大到合适比例，弹出体征卡。未摆放：地图不动，提示"这个人所在的基站（xxx）还没有摆放位置"，并给"去摆放"入口。

## 五、基站摆放

所有有账号的人都能用。

**流程**：

```text
1. 点地图右上角「摆放基站」进入摆放模式
2. 左边出现基站列表：搜索框、筛选（全部/未摆放/已摆放）；每行显示名称、区域、运行状态、是否已摆放；
   顶部提示"还有 N 个基站未摆放（共 M 个）"
3. 点一个未摆放的基站，鼠标变十字
4. 在地图上点击它应该在的位置，图上出现该基站图标；可拖动微调
5. 点「保存」写入数据库，点「取消」撤销这次改动
6. 保存后自动选中下一个未摆放的基站
```

列表按区域和名称排序，让相邻的基站排在一起。

摆放模式下还能：**移动**（拖动已摆放的基站，保存）、**改名**（起自己的名字，不改厂家名称）、**删除**（基站回到"未摆放"，需二次确认）。

**接口**：

| 接口 | 说明 |
| --- | --- |
| `GET /api/map/stations` | 全部基站：编码、名称、区域、运行状态、是否已摆放、坐标、版本号；`?placed=false` 只看未摆放 |
| `PUT /api/map/stations/{stationCode}/mark` | 新增或修改 |
| `DELETE /api/map/stations/{stationCode}/mark?version=` | 删除，带读到的版本号 |
| `GET /api/map/station-logs` | 操作日志（只读） |

`PUT` 请求体：

```json
{ "x": 39482000.5, "y": 3852000.5, "displayName": "新副井下口", "version": 0 }
```

新增时 `version` 传 0，修改时传读到的版本号。服务端校验：基站编码必须在 `POS_STATION` 里存在；`x`、`y` 必须在地图范围内，否则 400；`displayName` 最长 100 字符，去首尾空格。两人同时改或删同一基站，后提交的收到 409，提示"这个基站刚刚被 xxx 修改，请刷新"。两人同时第一次摆放同一基站（都传版本 0），后提交的会撞主键，同样返回 409。

**操作日志**：新增、移动、改名、删除都在**同一个数据库事务里**写一条日志（日志写失败则改动一并回滚）。记录：登录账号、时间、动作（`STATION_PLACE` / `STATION_MOVE` / `STATION_RENAME` / `STATION_DELETE`）、基站编码、改动前后的 `{ x, y, displayName }`。界面提供"查看操作记录"抽屉，倒序，可按基站筛选，服务端分页。

## 六、边界情况

| 情况 | 处理 |
| --- | --- |
| 厂家新增基站（`JZSS` 出现新编码） | 自动进入"未摆放"列表 |
| 厂家某基站不再出现 | 保留记录，摆放也保留 |
| 已摆放的基站状态为"通讯中断"或"故障" | 照常画，图标灰/红，体征卡提示"所在基站通讯异常，位置可能不准" |

## 七、验收

| 项目 | 期望 |
| --- | --- |
| 底图位置 | 网格点 `39482000, 3852000` 落在正确位置，无整体平移或翻转（验证 WMS 1.1.1） |
| 中文 | 巷道名称正常显示，无方块 |
| 摆放、拖动 | 摆 3 个基站，刷新后位置保持；拖动保存后位置更新，日志有含前后坐标的"移动"记录 |
| 删除 | 回到"未摆放"，日志有记录 |
| 并发 | 两个浏览器同时改、删或首次摆放同一基站，后提交的收到 409 |
| 日志不可改 | 数据库里直接更新/删除日志，被触发器拒绝（`TRUNCATE` 靠账号权限挡，见 `04`） |
| 人员定位 | 基站已摆放：图上有点、弹体征卡；未摆放：不画点、有提示 |
| 校验 | 范围外的坐标返回 400 |
