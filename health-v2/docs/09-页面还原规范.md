# 09 页面还原规范

目标：**页面布局和视觉风格与参考截图几乎一致**。截图存放在 `reference/screenshots/`（17 张，已被 Git 忽略），下文用"图 N"指其中编号为 N 的文件。

## 一、怎么用这份规范

**参考坐标**：截图里页面区域是 2000 × 968 像素（图 1 去掉浏览器顶部 160 像素后）。下文的坐标 `(x1,y1)-(x2,y2)` 都是这个区域内的像素位置，原点在页面左上角，误差约 ±10 像素。

**换算到实际画布**：设计画布用 1920 × 1080，横向乘 0.96，纵向乘 1.116（1080 ÷ 968）。两个方向比例不同，所以分两类处理：

- **面板、按钮、表格等方框**：按上面的比例拉伸，各块的相对位置和大小与截图一致。用比例（百分比）布局。
- **圆形和有固定形状的东西**（入口页大圆环和四个小圆环、头像、图标、视频、3D 人体）：按较小的比例 0.96 等比缩放，再放在换算后区域的中心，不能被拉成椭圆。

**地图的样子**：

- 背景是深色带纹理的底（像暗色的岩石），不是纯黑。
- 巷道用**彩色线条**画出：绿色、橙色、灰蓝色等，由 CAD 图层决定颜色。巷道名称是**白底黑字的小圆角标签**，沿巷道摆放。
- 人员图标：一个戴安全帽的小人，图标下面写姓名。
- **同一基站有多人时**，显示一个绿色圆点，里面写人数（截图里的 "4" "2" "3"）。

**体征卡弹窗（图 15）**：点人员后，在他的图标上方弹出一个青绿色的矩形卡片，下方有一个指向图标的小三角。卡片上半部分从上到下写（小字，白色，左对齐）：截图里是心率、体温、血氧、电量，我们按 `05` 的体征卡内容排（多了姓名、位置、血压和采集时间，见第九节第 14 项）；下半部分是一排文字按钮，用竖线分隔："告警记录"、"档案"。
